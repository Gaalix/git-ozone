Architecture Highlights

Engineered from the filesystem up — in pure Rust.

Zero libgit2, OpenSSL, or libfuse C library dependencies. Static binaries that probe your OS and automatically pick the fastest CoW backend.

Warm Cache & mtime Preservation

Auto-detects Rust (target/), Node/TS (node_modules/, .next/, .turbo/, .vite/), and Python (.venv/ with shebang trampolines). Preserves baseline mtime on untouched files so Cargo and tsc hit warm artifacts immediately.

Lock-Free MVCC OpLog & oz undo

Concurrent commits across 10+ workspaces never fail on .git/index.lock or packed-refs.lock. Every mutation and oz checkpoint appends an immutable OpLog entry for sub-10 ms oz undo / oz redo.

Addressable IDs & Built-In Guardrails

oz status and oz diff assign deterministic file (f1) and hunk (h1a) IDs. oz commit --pick builds trees in RAM while guarding against secrets, conflict markers, > 50 MB blobs, and out-of-scope edits.

Built-In oz mcp & 5 Agent Harnesses

oz agent setup configures skills/rules and oz checkpoint --quiet hooks for Claude Code, Cursor, Codex CLI, Windsurf, and Antigravity. oz mcp serves 8 structured tools over stdio JSON-RPC 2.0.

Native GitHub Stacked PRs & CI Logs

Pure-Rust Wire Protocol v2 (--filter=blob:none, --atomic, --force-with-lease), native Ed25519 SSH signing, oz pr stack, oz sync, and compact oz ci --json error excerpts for self-healing agent loops.

Zero Lock-In & oz git Shim

Colocated inside .git/ with real named branches and standard refs/notes/ai provenance. Optional alias git="oz git" intercepts 13 hot commands natively and wraps delegated legacy mutations in OpLog undo snapshots.

Live v1.0.0 Measured Benchmark Results (commit 3a240f354701)

Measured on AMD Ryzen 9 7900X (24 logical cores, 61.39 GiB RAM), Ubuntu Linux 7.3.0 (ext4), oz 1.0.0 vs git 2.55.0. Executed with --oz-backend cas_hardlink under Linux NoNewPrivs: 1 (which blocks setuid fusermount3). Run ./benchmarks/run_all.sh --full in a host shell (NoNewPrivs: 0) for the full 5 GB FUSE3 / native CoW run.

Honest trade-offs: Raw cold git worktree add without build caches (245.4 ms / 12.3 ms per ws) is still faster than warm oz ws spawn (941.1 ms), and under NoNewPrivs: 1 (cas_hardlink) workspace status walks all 250k files (226.5 ms vs 139.4 ms git) whereas regular-repo oz status beats git (117.0 ms) and host-shell linux_fuse3/ProjFS unlocks O(dirty_files) status.
