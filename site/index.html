Before you install

Do I have to convert my repository?

No. Ozone works inside the .git you already have, so git, gh, your editor and CI keep working.

What if I stop using it?

Delete .git/ozone. Your branches and commits were ordinary Git objects all along.

What does it depend on?

Nothing written in C. The binaries are static, pure Rust, with no libgit2, OpenSSL or libfuse.

What does it cost?

Nothing. Ozone is dual-licensed under MIT or Apache-2.0.

Install it in one line

curl -fsSL https://raw.githubusercontent.com/Gaalix/git-ozone/main/packaging/install.sh | bash
cargo install --git https://github.com/Gaalix/git-ozone --locked oz-cli oz-vfsd
brew install --formula https://raw.githubusercontent.com/Gaalix/git-ozone/main/packaging/homebrew/oz.rb
curl -fsSLO https://github.com/Gaalix/git-ozone/releases/download/v1.1.0/ozone_1.1.0_amd64.deb && sudo apt install ./ozone_1.1.0_amd64.deb
irm https://raw.githubusercontent.com/Gaalix/git-ozone/main/packaging/install.ps1 | iex
winget install OzoneVCS.Ozone
